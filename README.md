# Econgu Emmanuel — Personal Portfolio Website

A responsive personal portfolio website for Econgu Emmanuel, Biomedical and Mechatronics Engineering student at Kyambogo University, Uganda.

## Files

- `index.html` — main website page
- `assets/style.css` — layout, styling, responsive design
- `robots.txt` — search-engine crawling instructions
- `sitemap.xml` — sitemap for the website

## Before publishing

1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your real professional email address.
2. Update the project cards so they accurately describe your actual projects and their status.
3. Add your own LinkedIn or other professional profile links if you want them included.
4. Preview the page in a browser before publishing.

## Publish with GitHub Pages

1. Open the repository `econguemmanuel/econguemmanuel.github.io`.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `robots.txt`, `sitemap.xml`, `README.md`, and the complete `assets` folder.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Wait a few minutes and visit `https://econguemmanuel.github.io`.

If GitHub Pages is already configured for `main` and `/(root)`, the commit should trigger deployment automatically.

## Notes

The website uses Google Fonts when an internet connection is available; fallback fonts are included. The project entries are presented as concepts and areas of interest, not as claims of completed work.
